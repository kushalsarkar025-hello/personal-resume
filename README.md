## 🌟 About The Project

**Personal Resume Website** is a front-end web development project designed to present personal, academic and technical information in a structured and professional digital format.

Instead of relying entirely on a traditional paper-based resume, this project provides a web-based resume with an attractive interface, animated visual effects, responsive layouts and print-friendly styling.

The website is developed using pure HTML5 and CSS3, focusing on clean structure, visual presentation and responsive design.

## ✨ Key Features

- 🎨 **Modern UI Design** – Clean layout with an attractive blue gradient header.
- ✨ **Animated Glowing Effects** – CSS animations for headings, taglines, contact information and profile photography.
- 📱 **Responsive Layout** – Adapts to different screen sizes using CSS media queries.
- 📋 **Structured Resume Sections** – Organized presentation of educational and professional information.
- 🏷️ **Technical Skills Display** – Attractive skill chips for highlighting technical abilities.
- 📊 **Education Table** – Displays academic qualifications in a structured tabular format.
- 📄 **Print-Friendly Design** – Includes print-specific CSS styling for a cleaner printed resume.
- 🖼️ **Profile Photo Section** – Dedicated profile image area with styling and glowing effects.

## 📑 Website Sections

The website contains the following sections:

1. **Header** – Name, professional tagline, contact information and profile photograph.
2. **Career Objective** – Professional goals and career aspirations.
3. **Educational Qualification** – Academic history and examination results.
4. **Technical Skills** – Programming languages, software knowledge and technical abilities.
5. **Projects** – Selected academic and programming projects.
6. **Reports During Curriculum Assessments** – Academic reports and project descriptions.
7. **Achievements** – Technical workshops, seminars and certifications.
8. **Strengths** – Personal strengths, communication skills and known languages.
9. **Declaration** – Formal declaration of the information provided.

## 🚀 Getting Started

You can run this project locally by following these simple steps.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Personal-Resume-Website.git
```

### 2. Navigate to the Project Folder

```bash
cd Personal-Resume-Website
```

### 3. Open the Website

Open `index.html` in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.

**Note:** No additional frameworks, libraries or package installations are required.

## 📱 Responsive Design

The website uses CSS media queries to improve its presentation across different screen sizes.

- Desktop: Full resume layout with profile information alongside the header.
- Tablet: Flexible content arrangement.
- Mobile: Stacked header, centered contact information and adjusted typography.
