# 👨‍💻 Personal Resume Website

A simple and responsive personal resume website built using **HTML5 and CSS3**. It presents educational qualifications, technical skills, projects, achievements and personal information in a clean and professional format.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

---

## ✨ Features

- Clean and professional design.
- Attractive blue gradient header.
- Animated glowing text effects.
- Personal profile photo section.
- Educational qualification table.
- Technical skills and project details.
- Responsive layout for different screen sizes.
- Print-friendly resume design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Animations
- Media Queries

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/Personal-Resume-Website.git
```

2. Open the project folder in VS Code.

3. Open `index.html` in your web browser.

You can also use the Live Server extension in VS Code.
